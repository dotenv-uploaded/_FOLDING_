# Folding application icon

The application icon is derived from the PNG supplied by the project owner:

`https://cdn.discordapp.com/attachments/1527272449622671493/1529075249298276383/47bd150e-4c5d-4173-aea0-b1452a9a7cef.png`

The downloaded image is stored unchanged as `build/icon.png`. electron-builder uses that single PNG as the icon
source for Windows, macOS, and Linux and performs the target-specific conversion during packaging.

Keep the source at 1024×1024 or larger if it is replaced.
