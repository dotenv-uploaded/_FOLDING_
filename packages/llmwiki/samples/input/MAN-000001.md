# 운영 매뉴얼 1

## 제1절 근거

1. 계정 생성

1. 승인된 계정 신청서의 사용자와 부서를 확인한다.

4. 사용자에게 별도 채널로 초기 접속 방법을 전달한다.

본 문서는 사용자 계정의 생성 및 권한 변경에 대한 운영 절차를 다루고 있다. 계정 관리 시 준수해야 할 확인 목록과 상위 규정을 명시하여 운영의 일관성을 유지한다.

계정 생성 시 신청서 확인, 중복 검색, 역할 부여 및 사용자 통지 절차를 수행한다.

권한 변경 시 승인자와 종료일을 확인하고 최소 권한 원칙을 준수한다.

## 제2절 근거

2. 권한 변경
