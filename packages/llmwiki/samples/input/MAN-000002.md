# 운영 매뉴얼 2

## 제1절 근거

요청일, 요청 유형, 대상 정보 및 회신 방법을 기록한다.

본인 확인에 필요한 정보는 요청 처리 목적에 필요한 범위로 제한한다.

본 문서는 개인정보 요청 접수부터 처리, 제한 사항까지의 절차를 규정한 매뉴얼이다. 요청 접수 시 본인 확인 범위를 제한하고, 처리 단계별 담당자와 확인 사항을 명시한다.

요청 접수 시 본인 확인 정보는 처리 목적에 필요한 범위로 제한한다.

개인정보 요청 처리는 접수, 검토, 조회, 회신의 4단계 흐름으로 진행된다.

제3자 권리 침해 등 처리 제한 사유 발생 시 근거와 대체 조치를 안내해야 한다.

개인정보 요청 처리 시 본인 확인 정보는 어디까지 수집할 수 있나요?

요청 처리 목적에 필요한 범위로 제한하여 수집해야 합니다.

개인정보 요청 처리가 제한되는 경우는 언제인가요?

제3자의 권리를 침해하거나 법령상 제한 사유가 있는 경우입니다.

## 제2절 근거

접수 | 고객지원 | 요청 내용과 연락처

검토 | 개인정보보호팀 | 법적 제한 및 본인 여부

조회 | 시스템 담당 | 대상 데이터와 보유 위치

## 제3절 근거

제3자의 권리를 침해하거나 법령상 제한 사유가 있는 경우 근거와 가능한 대체 조치를 함께 안내한다.

관련 기준은 [개인정보 처리 규정](REG-000003.md)을 따른다.
