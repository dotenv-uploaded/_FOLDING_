# 업무 규정 20

## 제1절 근거

검토 중인 초안으로 아직 효력이 없다.

승인된 서비스와 계정을 사용하며 입력하려는 정보의 등급과 서비스의 데이터 처리 조건을 사전에 확인한다.

본 문서는 생성형 AI를 업무에 활용할 때 준수해야 할 허용 원칙과 금지사항, 결과 검토 책임을 규정한 초안이다. 현재 검토 중인 단계로 아직 공식적인 효력은 발생하지 않았다.

승인된 서비스와 계정만을 사용하며 데이터 처리 조건을 사전에 확인해야 한다.

비밀번호, 기밀정보, 개인정보 등의 입력을 금지한다.

생성 결과에 대한 검증 의무와 최종 책임은 사용자에게 있다.

데이터 처리 조건

생성형 AI 사용 시 금지되는 정보 입력은 무엇인가요?

비밀번호, 비밀키, 인증 토큰, 승인되지 않은 서비스에 대한 기밀정보, 타인의 저작물이나 개인정보 입력이 금지됩니다.

생성형 AI 결과물을 사용할 때 주의할 점은 무엇인가요?

사용자는 결과의 정확성, 편향, 출처 및 보안 영향을 직접 확인해야 하며, 최종 산출물에 대한 책임을 집니다.

## 제2절 근거

비밀번호, 비밀키 및 인증 토큰 입력

## 제3절 근거

사용자는 생성 결과의 정확성, 편향, 출처 및 보안 영향을 확인하고 최종 산출물에 대한 책임을 진다.
