# 운영 매뉴얼 7

## 제1절 근거

1. 작업 전

- [ ] 승인번호 확인

본 문서는 시스템 변경 작업 시 준수해야 할 단계별 절차를 정의한 매뉴얼이다. 작업 전 준비 사항부터 작업 중 기록, 작업 후 결과 보고까지의 과정을 포함한다.

작업 전 승인번호 확인, 영향 범위 파악, 백업 생성 및 되돌리기 조건을 확인해야 한다.

작업 중에는 계획된 시각과 결과를 기록하며, 오류 발생 시 임의로 범위를 확대하지 않는다.

작업 후에는 핵심 기능과 모니터링 상태를 확인하고 승인자에게 결과를 보고해야 한다.

작업 중 오류가 발생하면 어떻게 해야 하나요?

계획된 단계별 시작·종료 시각과 결과를 기록하고, 임의로 작업 범위를 확대하지 않아야 합니다.

작업이 실패했을 때도 기록을 남겨야 하나요?

네, 실패한 작업도 동일하게 기록해야 합니다.

## 제2절 근거

3. 작업 후

핵심 기능과 모니터링 상태를 확인하고 변경 결과를 승인자에게 알린다.

상위 기준은 정보시스템 변경관리 규정이다.

실패한 작업도 동일하게 기록한다.

상위 기준은 [정보시스템 변경관리 규정](REG-000011.md)이다.

## 제3절 근거

계획된 단계별 시작·종료 시각과 결과를 기록한다. 예상하지 못한 오류가 발생하면 임의로 범위를 확대하지 않는다.
