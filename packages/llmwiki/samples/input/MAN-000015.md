# 운영 매뉴얼 15

## 제1절 근거

자산번호, 사용자, 기기 식별정보 및 운영체제 지원 여부를 확인한다.

본 문서는 업무용 모바일기기의 등록 전 확인 사항, 기본 보안 설정, 그리고 사용자 인계 절차를 안내한다. 기기 관리의 표준 가이드로서 보안 규정을 준수하여 설정하도록 규정한다.

등록 전 자산번호 및 운영체제 지원 여부 확인

화면 잠금, 암호화, 프로파일 등록 등 기본 보안 설정 수행

분실 신고 및 해외 사용 주의사항 등 사용자 인계 절차 준수

모바일

초기설정

자산번호

기기관리 프로파일

저장공간 암호화

원격 잠금

분실 신고

금지 앱

모바일기기 보안 규정

업무용 모바일기기 설정 시 필수 보안 설정 항목은 무엇인가요?

화면 잠금과 자동 잠금시간 설정, 저장공간 암호화 확인, 기기관리 프로파일 등록, 원격 잠금 및 삭제 활성화, 승인된 업무 앱 설치가 필요합니다.

사용자 인계 시 안내해야 할 주요 사항은 무엇인가요?

분실 신고 방법, 금지 앱, 백업 범위 및 해외 사용 시 주의사항을 안내해야 합니다.

## 제2절 근거

적용 기준은 모바일기기 보안 규정이다.

사용자에게 분실 신고 방법, 금지 앱, 백업 범위 및 해외 사용 시 주의사항을 안내한다.

적용 기준은 [모바일기기 보안 규정](REG-000019.md)이다.

## 제3절 근거

- 화면 잠금과 자동 잠금시간 설정

- 기기관리 프로파일 등록
