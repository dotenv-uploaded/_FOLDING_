# 업무 규정 16

## 제1절 근거

업무자료는 승인된 전자우편과 메신저를 통해 전달한다.

개인 계정이나 승인되지 않은 파일전송 서비스는 사용하지 않는다.

본 규정은 업무 수행 시 전자우편과 메신저의 안전한 사용을 위한 지침을 명시한다. 업무자료 전달 시 승인된 계정 사용, 발송 전 정보 확인, 의심 메시지 대응 절차를 규정하고 있다.

업무자료 전달 시 반드시 승인된 전자우편과 메신저 계정을 사용해야 한다.

메시지 발송 전 수신자, 첨부파일, 기밀정보 포함 여부 및 개인정보 노출 방지를 확인해야 한다.

출처가 불분명한 링크나 첨부파일은 열람을 금지하며, 실행 시 네트워크를 차단하고 즉시 신고해야 한다.

업무자료를 개인 계정으로 전달해도 되나요?

아니요, 업무자료는 반드시 승인된 전자우편과 메신저를 통해 전달해야 하며 개인 계정 사용은 금지됩니다.

출처가 불분명한 링크를 이미 클릭했다면 어떻게 해야 하나요?

즉시 네트워크를 차단하고 신고해야 합니다.

## 제2절 근거

수신자 주소와 참조자를 확인한다.

## 제3절 근거

이미 실행했다면 네트워크를 차단하고 즉시 신고한다.
