# 운영 매뉴얼 3

## 제1절 근거

반출 파일의 목록과 정보등급을 작성하고 수신자, 목적, 전달 수단, 회수 또는 삭제 예정일을 입력한다.

본 매뉴얼은 자료 반출 시 신청, 보호조치, 완료 확인 단계에 대한 운영 절차를 규정한다. 자료의 안전한 외부 전송을 위해 암호화 및 수신 확인 절차를 준수해야 한다.

자료 반출 신청 시 파일 목록, 정보등급, 수신자, 목적, 전달 수단, 회수/삭제 예정일을 입력해야 한다.

기밀 파일은 암호화 후 승인된 전송수단을 이용하며, 비밀번호는 별도로 전달해야 한다.

반출 후 수신 여부를 확인하고, 만료일 경과 시 수신자의 삭제 또는 반환 여부를 확인해야 한다.

기밀 파일 전송 시 비밀번호는 어떻게 전달해야 하나요?

비밀번호는 압축파일과 별도로 전달해야 하며, 전자우편 본문에 함께 기록해서는 안 됩니다.

자료 반출 후 사후 관리는 어떻게 하나요?

반출 후 수신 여부를 확인하고, 만료일이 지나면 수신자가 자료를 삭제하거나 반환했는지 확인해야 합니다.

## 제2절 근거

기밀 파일 → 암호화 → 승인된 전송수단 → 비밀번호 별도 전달

압축파일 비밀번호를 같은 전자우편 본문에 기록하지 않는다.

## 제3절 근거

반출 후 수신 여부를 확인하고 만료일이 지나면 수신자의 삭제 또는 반환 여부를 확인한다.
