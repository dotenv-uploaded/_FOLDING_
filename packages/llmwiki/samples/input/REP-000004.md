# 점검 보고서 4

## 제1절 근거

관리자 계정 탈취와 외부 데이터 전송 징후가 동시에 탐지된 상황을 가정했다.

본 문서는 관리자 계정 탈취와 외부 데이터 전송 상황을 가정한 침해사고 대응 모의훈련 결과 보고서이다. 훈련 측정 결과와 함께 식별된 개선사항 및 적용된 매뉴얼을 포함하고 있다.

관리자 계정 탈취와 외부 데이터 전송 징후를 가정한 모의훈련을 실시함.

최초 신고와 담당자 소집은 목표를 달성했으나 영향 범위 식별은 지연됨.

클라우드 로그 담당자 연락 지연 문제를 해결하기 위해 비상연락망과 체크리스트를 갱신함.

외부 데이터 전송

영향 범위 식별

비상연락망

초기 분석 체크리스트

정보보호 사고 대응 매뉴얼

이번 모의훈련에서 가장 지연된 대응 항목은 무엇인가?

영향 범위 식별 항목으로, 목표 시간 60분을 초과한 74분이 소요되었다.

훈련 결과에 따른 개선사항은 무엇인가?

클라우드 로그 담당자 연락 지연 문제를 개선하기 위해 비상연락망과 초기 분석 체크리스트를 갱신하기로 했다.

## 제2절 근거

영향 범위 식별 | 60분 | 74분 |

## 제3절 근거

클라우드 로그 담당자 연락이 지연되었다. 비상연락망과 초기 분석 체크리스트를 갱신하기로 했다.

훈련 기준은 정보보호 사고 대응 매뉴얼을 적용했다.
